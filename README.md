## 📖 О проекте

**Fiesta Store** — это полноценный интернет-магазин мебели, разработанный с использованием современных веб-технологий. Проект демонстрирует возможности Next.js 15, TypeScript и Tailwind CSS для создания быстрых, красивых и функциональных веб-приложений.

### ✨ Основные возможности

- 🏠 **Главная страница** с hero-секцией, популярными категориями и отзывами клиентов
- 🛍️ **Каталог товаров** с фильтрацией по категориям
- 📦 **Страница товара** с интерактивной галереей, характеристиками и похожими товарами
- 🏪 **Шоу-рум** с витринными экземплярами со скидками
- 🛒 **Корзина** с сохранением в LocalStorage
- ⭐ **Отзывы** с формой отправки и модерацией
- 📱 **Полная адаптивность** для мобильных, планшетов и десктопов
- 🎨 **Современный дизайн** с анимациями и hover-эффектами
- 🔍 **SEO-оптимизация** с мета-тегами и Open Graph
- 📄 **Юридические страницы** (политика конфиденциальности, пользовательское соглашение)

## 🛠️ Технологии

| Технология       | Версия | Назначение                      |
| ---------------- | ------ | ------------------------------- |
| **Next.js**      | 15.x   | React-фреймворк с SSR и SSG     |
| **TypeScript**   | 5.x    | Типизация для надёжного кода    |
| **Tailwind CSS** | 3.4    | Utility-first CSS фреймворк     |
| **React**        | 19.x   | UI библиотека                   |
| **Zustand**      | 5.x    | Управление состоянием (корзина) |
| **Vercel**       | -      | Хостинг и деплой                |
