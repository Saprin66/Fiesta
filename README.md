## 📖 О проекте

**Fiesta Store** — это современный интернет-магазин мебели, разработанный с использованием передовых веб-технологий. Проект демонстрирует лучшие практики создания быстрых, SEO-оптимизированных и удобных для пользователя веб-приложений на базе Next.js App Router.

### ✨ Ключевые возможности

- 🏠 **Главная страница**: Hero-секция, популярные категории с hover-эффектами и красивый блок "Почему выбирают нас" с градиентными карточками.
- 🛍️ **Каталог**: Фильтрация товаров по категориям с мгновенным обновлением UI.
- 📦 **Страница товара**: Интерактивная галерея с переключением фото по клику, характеристики и блок "Похожие товары".
- 🏪 **Шоу-рум**: Специальный раздел для витринных экземпляров со скидками.
- 🛒 **Умная корзина**: Добавление, удаление, изменение количества. Данные сохраняются в `LocalStorage` и не пропадают при перезагрузке.
- ⭐ **Система отзывов**: Модальная форма с валидацией, интерактивными звёздами и сохранением новых отзывов в `LocalStorage`.
- 📱 **Полная адаптивность**: Идеальное отображение на мобильных устройствах, планшетах и десктопах.
- 📄 **Юридическая база**: Готовые страницы "Политика конфиденциальности" и "Пользовательское соглашение" (в соответствии с 152-ФЗ).
- 🎨 **Кастомные иконки**: SVG-иконки соцсетей в футере без сторонних тяжёлых библиотек.

## 🚀 Быстрый старт

### Требования

- Node.js 18.x или выше
- Менеджер пакетов: `npm`, `yarn` или `pnpm`

### Установка и запуск

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/your-username/fiesta-store.git
   cd fiesta-store
   ```

2. **Установите зависимости**

   ```bash
   npm install
   ```

3. **Запустите сервер разработки**

   ```bash
   npm run dev
   ```

4. **Откройте браузер**
   Перейдите по адресу [http://localhost:3000](http://localhost:3000)

## 📂 Структура проекта

```text
fiesta-store/
├── public/
│   └── images/              # Статические изображения (категории, соцсети)
├── src/
│   ├── app/                 # Маршруты приложения (Next.js App Router)
│   │   ├── page.tsx         # Главная страница
│   │   ├── catalog/
│   │   │   ├── page.tsx     # Каталог с фильтрами
│   │   │   └── [id]/
│   │   │       └── page.tsx # Динамическая страница товара
│   │   ├── showroom/        # Раздел витринных товаров
│   │   ├── cart/            # Страница корзины
│   │   ├── privacy/         # Политика конфиденциальности
│   │   └── terms/           # Пользовательское соглашение
│   ├── components/          # Переиспользуемые UI-компоненты
│   │   ├── Header.tsx       # Шапка с навигацией и счётчиком корзины
│   │   ├── Footer.tsx       # Подвал с ссылками и соцсетями
│   │   ├── ProductCard.tsx  # Карточка товара для каталога
│   │   ├── ProductGallery.tsx # Клиентский компонент галереи товара
│   │   ├── ReviewCard.tsx   # Карточка отзыва
│   │   └── ReviewForm.tsx   # Модальная форма добавления отзыва
│   ├── data/                # Локальные данные (до подключения БД)
│   │   ├── products.ts      # Массив товаров
│   │   └── reviews.ts       # Базовые отзывы
│   ├── hooks/               # Кастомные хуки
│   │   └── useReviews.ts    # Хук для объединения базовых и user-отзывов
│   ├── lib/                 # Утилиты
│   │   └── reviewsStorage.ts # Логика работы с LocalStorage для отзывов
│   └── store/               # Глобальное состояние
│       └── cartStore.ts     # Zustand store для корзины
├── next.config.ts           # Настройки Next.js (оптимизация изображений)
├── tailwind.config.ts       # Конфигурация Tailwind CSS
└── package.json             # Зависимости и скрипты
```

## 🎯 Технические особенности

1. **Оптимизация производительности**:
   - Использование `next/image` с атрибутом `sizes` для загрузки изображений нужного разрешения.
   - Разделение на Серверные (`page.tsx`) и Клиентские (`'use client'`) компоненты для минимизации размера JS-бандла.
2. **Устойчивость к ошибкам**:
   - Fallback-изображения, если фото товара не загрузилось.
   - Валидация формы отзывов перед отправкой.
3. **SEO**:
   - Динамические мета-теги (`generateMetadata`) для каждой страницы товара.
   - Семантическая вёрстка (`<main>`, `<article>`, `<nav>`, `<h1>`-`<h3>`).
