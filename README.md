# Fiesta Store

Интернет-магазин мебели: каталог, шоу-рум с витринными образцами, корзина с сохранением, оформление заказа и админ-панель.

**Стек:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Prisma 7 + PostgreSQL, Zustand, Lucide, Zod.

## Возможности

- Каталог с фильтрами по категории, цене и наличию, поиском и сортировкой.
- Карточка товара с галереей, характеристиками и разметкой schema.org.
- Шоу-рум: витринные образцы со скидкой, состоянием и причиной скидки.
- Корзина в `localStorage` (переживает перезагрузку и закрытие вкладки), выезжающая мини-корзина.
- Оформление заказа как заявки: цены пересчитываются на сервере, заказ сохраняется в базе.
- Формы обратной связи и отзывов (отзывы публикуются после модерации).
- Админка `/admin`: товары с загрузкой фото, категории, заказы со статусами, заявки, отзывы.

## Локальный запуск

```bash
cp .env.example .env        # заполнить DATABASE_URL, AUTH_SECRET, ADMIN_EMAIL, ADMIN_PASSWORD
npm install
npm run db:deploy           # применить миграции
npm run db:seed             # перенести стартовые товары и создать администратора
npm run dev
```

Админка: http://localhost:3000/admin (логин и пароль из `ADMIN_EMAIL` / `ADMIN_PASSWORD`).

После изменения `prisma/schema.prisma` создайте миграцию: `npm run db:migrate -- --name описание`.

## Деплой на Render

В репозитории есть `render.yaml` (Blueprint): веб-сервис + PostgreSQL.

1. Render → **New → Blueprint** → выбрать этот репозиторий.
2. Указать `ADMIN_EMAIL`, `ADMIN_PASSWORD` и `SITE_URL` (адрес сайта, например `https://fiesta.onrender.com`). `DATABASE_URL` и `AUTH_SECRET` Render подставит сам.
3. При каждом запуске применяются миграции, а при пустой базе переносятся стартовые товары и создаётся администратор.

Бесплатная база Render удаляется через 30 дней, для продакшена нужен платный план базы. Бесплатный веб-сервис засыпает без трафика, первый заход после паузы медленный.

Без `DATABASE_URL` и `AUTH_SECRET` сборка останавливается намеренно, чтобы не выкатить сайт без базы.

## Структура

```
prisma/              схема, миграции, seed и стартовые данные (seed-data/)
src/app/(shop)/      страницы магазина
src/app/admin/       админ-панель и её server actions
src/app/api/         отдача фото из базы, загрузка фото, health-check
src/components/      UI-компоненты (ui/ — дизайн-система, cart/ — корзина)
src/lib/             работа с БД, авторизация, корзина, валидация
```

Фото, загруженные через админку, сжимаются в WebP (до 1600px) и хранятся в PostgreSQL.
